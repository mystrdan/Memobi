# MEMO Economics

## Status

Economics are preliminary and must not be treated as final mainnet parameters.

## Native asset

- Name: MEMO
- Smallest unit: tentatively 0.00000001 MEMO
- Model: native blockchain currency
- No token contract

## Supply

A maximum supply has not been frozen.

100,000,000 MEMO is currently a design candidate, but final supply must be derived alongside block interval, block subsidy, emission schedule, expected miner participation, long-term security budget, and fee economics.

## Issuance

The preferred direction is a declining block subsidy rather than an indefinitely constant reward.

A final emission curve must be mathematically specified before mainnet.

## Premine

The current direction is no premine.

Genesis allocation, if any, must be explicitly justified and documented before a mainnet genesis block is created.

## Fees

Memobi is intended to use small, predictable transaction fees rather than smart-contract gas.

## Mining economics

The central economic question is not simply how many phones can mine.

It is whether a smartphone-class device can earn a meaningful share of network Proof-of-Work without requiring industrial-scale hardware.

The PoARM laboratory must inform this decision before the emission schedule is finalized.
